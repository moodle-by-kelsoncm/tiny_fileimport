Visão Geral - moodle-tiny_fileimport
====================================

O **moodle-tiny_fileimport** é um plugin para o editor TinyMCE do Moodle que adiciona o item **File import** ao menu **Insert**, permitindo o envio de arquivos diretamente pelo editor via arrastar e soltar (*drag & drop*) ou janela modal.

Recursos Principais
-------------------

- **Item no Menu Inserir**: Opção nativa *File import* integrada ao TinyMCE.
- **Interface Modal & Drag and Drop**: Envio rápido arrastando arquivos para a janela ou diretamente para o corpo do editor.
- **Integração com Repositórios do Moodle**: Utiliza a Repository API nativa para armazenamento seguro de arquivos.
- **Inserção Automática de Links**: Criação imediata da tag HTML de link formatado (`<a href="...">arquivo</a>`).
- **Controle de Tipos Permitidos**: Políticas de extensões e tipos MIME configuráveis pela administração.
