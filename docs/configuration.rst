Configuração
============

Políticas de Arquivos
---------------------

Acesse **Administração do site > Servidor > Tipos de arquivos** (`admin/tool/filetypes`) para gerenciar os tipos de arquivos e extensões suportados globalmente.

Opções Adicionais
-----------------

- Possibilidade de sobrescrever a lista de extensões permitidas especificamente para o editor TinyMCE.
- Ativação do modo permissivo total (`*`) ou restrição a extensões específicas como `.pdf`, `.docx`.
