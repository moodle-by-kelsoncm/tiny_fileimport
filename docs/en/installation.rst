Installation
============

Requirements
------------

- **Moodle**: 4.5 or higher (minimum required version `2024100700`)
- **PHP**: 8.1 or higher supported by your Moodle release

Installation Procedure
----------------------

1. Access the TinyMCE plugins directory in your Moodle installation:

   .. code-block:: bash

      cd /path/to/moodle/lib/editor/tiny/plugins

2. Clone the repository naming the folder `fileimport`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/tiny_fileimport.git fileimport

3. Access **Site administration > Notifications** in Moodle to complete the installation.
