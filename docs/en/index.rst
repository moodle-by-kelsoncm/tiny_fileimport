Overview - moodle-tiny_fileimport
==================================

**moodle-tiny_fileimport** is a plugin for Moodle's TinyMCE editor that adds the **File import** item to the **Insert** menu, allowing file uploads directly through the editor via drag & drop or a modal window.

Key Features
------------

- **Insert Menu Item**: Native *File import* action integrated into TinyMCE.
- **Modal & Drag and Drop Interface**: Fast upload by dragging files into the dialog or directly into the editor body.
- **Moodle Repository Integration**: Utilizes the native Repository API for secure file storage.
- **Automatic Link Insertion**: Generates formatted HTML link tags immediately (`<a href="...">filename</a>`).
- **Allowed Types Control**: File extension and MIME type policies configurable by site administration.
