User Guide
==========

Importing Files through the Editor
----------------------------------

1. In the TinyMCE editor, open the **Insert** menu and click **File import**.
2. In the modal dialog displayed, drag the desired file or click to choose from your computer.
3. The file will be uploaded via Moodle API and automatically inserted as a formatted link with the original file name.
4. Alternatively, drag the file directly from your operating system into the editor's text area.
