Instalação
==========

Requisitos
----------

- **Moodle**: 4.5 ou superior (versão mínima exigida `2024100700`)
- **PHP**: 8.1 ou superior suportado pela sua versão do Moodle

Procedimento de Instalação
--------------------------

1. Acesse o diretório de plugins do TinyMCE na sua instalação Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/lib/editor/tiny/plugins

2. Clone o repositório nomeando a pasta como `fileimport`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/tiny_fileimport.git fileimport

3. Acesse a área **Administração do site > Notificações** no Moodle para concluir a instalação.
