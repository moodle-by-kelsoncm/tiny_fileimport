Guia de Uso
===========

Importando Arquivos pelo Editor
-------------------------------

1. No editor TinyMCE, abra o menu **Insert** e clique em **File import**.
2. Na janela modal exibida, arraste o arquivo desejado ou clique para selecionar do seu computador.
3. O arquivo será enviado via API do Moodle e inserido automaticamente como link com o nome original do arquivo.
4. Alternativamente, arraste o arquivo do seu sistema operacional diretamente para dentro da área de texto do editor.
